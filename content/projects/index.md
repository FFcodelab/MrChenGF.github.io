这里用于整理项目实践，目前尚未添加个人项目。

## 每个项目值得说明的事

| 方面 | 建议记录 |
| --- | --- |
| 背景与约束 | 要解决什么问题，资源和时间受什么限制 |
| 我的职责 | 自己实际负责的部分 |
| 设计与实现 | 关键模块、接口、状态机和调用链 |
| 方案取舍 | 为什么采用这个方案，代价是什么 |
| 测试与结果 | 如何验证，有什么数据或证据 |
| 复盘 | 尚未解决的问题和后续改进 |

涉及原单位项目时，使用可以公开的描述和自己有权公开的材料。

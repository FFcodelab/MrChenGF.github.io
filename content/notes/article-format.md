## 代码与说明

代码块标记语言后，网站会进行语法高亮。下面只是 C 语言代码块的展示：

```c
#include <stdint.h>

uint32_t set_bit(uint32_t value, uint32_t bit)
{
    if (bit >= 32U) {
        return value;
    }
    return value | (UINT32_C(1) << bit);
}
```

涉及真实硬件时，寄存器语义、访问宽度和并发条件应当根据芯片手册与实际源码另行说明。
